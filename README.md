# Dorkus# Simple BMI Calculator

A clean, responsive Body Mass Index (BMI) calculator built with pure HTML, CSS, and JavaScript. 

## Features
- **Toggle Units:** Switch seamlessly between Metric (cm/kg) and Imperial (inches/lbs).
- **Instant Calculation:** Accurate BMI calculation with one click.
- **Dynamic Feedback:** Color-coded health categories (Underweight, Normal, Overweight, Obese) based on WHO standards.
- **Responsive Design:** Looks great on both desktop and mobile devices.

## Tech Stack
- HTML5
- CSS3 (Custom styling, Flexbox)
- Vanilla JavaScript (ES6+)
